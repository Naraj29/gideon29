### 🩺 1. AI Doctors & Healthcare (`doctor.momen2`)
Medical data demands absolute sovereignty and instant latency. Gideon runs on-premise without transmitting sensitive patient histories or health telemetry to third-party clouds.
- **Biometric & Habit Telemetry**: Directly interfaces with the **Life Tracker** to monitor sleep patterns, hydration, daily productivity scores, and physical wellness.
- **Clinical Triage & Checklists**: Utilizes **Task Sanctuary** to manage critical patient follow-ups, diagnostic protocols, and triage queues.
- **Confidential Asset Protection**: Encrypted records and sensitive clinical credentials secured via **The Vault** using client-side encryption.
- **Patient Journey Logging**: Chronological health reflection and treatment diaries powered by **Personal Diary**.

### 🎓 2. AI Teachers & Personalized Education (`learn.momen2.com`)
True education requires adaptive pacing, structured roadmaps, and bilingual accessibility.
- **Socratic 1-on-1 AI Tutor**: Gideon explains complex physics, mathematical derivations, coding paradigms, and history on demand.
- **Curriculum & Exam Architecture**: Builds structured milestones and revision deadlines using **Event Architect**.
- **Tactical Study Blocks**: Formulates focused daily study rhythms and timetable schedules with **Timetable Maker**.
- **Knowledge Vault**: Organizes lecture summaries, scientific formulas, and deep research via **Note Archive**.
- **Universal Bilingual Delivery**: Instant toggle between **English** and **Hindi (हिन्दी)** allows students to learn without linguistic barriers.

### 🔍 3. Deep Universal Search (`search.momen2.com`)
- **Federated Workspace Indexing**: Instant semantic and lexical search across all notes, tasks, diary entries, media archives, and projects.
- **Zero-Latency Querying**: Local search operates in microseconds without dependency on external search APIs.

### 🤝 4. Decentralized Community & Trust (`social.momen2`)
- **DropZone P2P Transfer**: High-speed, local Wi-Fi peer-to-peer file sharing without internet connectivity or cloud servers.
- **QR Studio**: Instant optical scanning and cryptographically clean matrix generation.
- **Media Tracker**: Unified media curation for literature, documentaries, films, games, and research materials.
- **Promise Tracker**: Digital ledger enforcing accountability, mutual pledges, and integrity metrics.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **Ollama**: Local AI runner ([Download Ollama](https://ollama.com))

### 2. Pull Ollama Model
Gideon defaults to the ultra-fast, lightweight 1.5B parameter model (recommended for low latency):
```bash
ollama run qwen2.5:1.5b
```

### 3. Start Backend Proxy
```bash
cd backend
npm install
node server.js
```
The backend initializes at `http://localhost:3010`.  
Verify health status at `http://localhost:3010/health`.

### 4. Start Frontend
```bash
cd frontend
npm install
npm run dev
```
Access the application in your browser at `http://localhost:3000` (or the port specified by Vite).
